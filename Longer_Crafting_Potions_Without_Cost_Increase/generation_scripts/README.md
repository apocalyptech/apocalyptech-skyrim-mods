Longer Crafting Potions Without Cost Increase Generation Script
===============================================================

This mod is 100% entirely generated by an
[xEdit/SSEEdit](https://github.com/TES5Edit/TES5Edit) script which
is included here.

Configuration
=============

If you open up the script in a text editor you'll see an area near
the top where you can change both the scaling value, and the list
of effects which the script will buff.  Alter those to suit at will!
(You can also edit the script right inside xEdit between selecting
the script and hitting the "run" button.)

Generation
==========

1. Copy `Create_Longer_Potion_Duration.pas` into your SSEEdit `Edit
   Scripts` directory
2. Launch SSEEdit
3. Right click on anything and run the script.  It'll prompt you for
   a filename to save the new `.esp` file.

That's basically it!
